# 同词相见

一个双人实时网页小游戏。两个人先各自写一个词，揭晓后再顺着彼此的词继续联想，直到某一轮说出同一个词。

## 功能

- 6 位房间号与邀请链接
- 30 / 45 / 60 秒回合时间
- 双方隐藏写词、同时揭晓
- 房主权威状态与自动重连
- 手机和桌面布局
- 邀请二维码、复制链接、系统分享
- 历史轮次与再来一局

## 本地开发

```bash
npm install
npm run dev
```

生产构建：

```bash
npm test
npm run build
```

## 联机说明

网页本身是静态站点，房间通过公开 MQTT WebSocket 通道同步。房主页面维护当前房间状态，另一位玩家通过随机房间主题收发事件。未揭晓的词不会写入公开同步消息或远端数据库。

房主需要在本局结束前保持页面打开。房间记录最多保留在房主浏览器的本地存储中 7 天。
